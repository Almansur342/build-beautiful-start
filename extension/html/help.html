Start here

Quick start workflow

  1. Open a target website and click the floating Scan button, or paste multiple URLs into Bulk Scanner.
  2. Open Evidence Vault and expand a website card. The Manage this lead panel appears first.
  3. Review emails, social links, phones, technologies, SEO checks, opportunity signals, and domain-age evidence.
  4. Set stage, priority, contacted status, industry, country, follow-up date, tags, pain labels, and notes.
  5. Use clipboard buttons for reusable text. Use Export XLSX or Download backup only when you need a file.
Discovery

Website scanning

Public contact discovery

LeadLens captures public emails, social profiles, and phone or WhatsApp-like contact paths from the visible page, links, footer, attributes, structured data, and selected same-domain contact or about pages.

Technology detection

Common CMS, frameworks, analytics, CDN, ecommerce, security, and implementation signals help you understand the public website stack.

SEO and conversion evidence

Title, description, headings, images, links, schema, robots.txt, sitemap, local performance observations, CTA paths, trust signals, and website-improvement notes remain reviewable.

Partial or failed scans

If a website blocks loading or times out, LeadLens keeps a reviewable record instead of silently dropping the URL. You can retry later.

Batch workflow

Bulk scanner with resumable URL workspace

Paste one website per line. The URL list is saved automatically inside this Chrome profile. If the browser closes, the computer restarts, or scanning is paused, remaining URLs and recent progress are restored when Evidence Vault opens again.

Focus rotationKeep Rotate active scan tabs enabled for websites that load correctly only while their tab is active. LeadLens briefly switches between controlled scan tabs and returns to Evidence Vault after the batch finishes.
Workspace

Evidence Vault

Evidence Vault is the central browser-based workspace. It loads a lightweight paginated index first. Full SEO, technology, contact, and CRM evidence is loaded only when you expand a lead card, which keeps large datasets responsive.

CRM

Manual lead decisions override automatic defaults

LeadLens can suggest initial country, industry, stage, and priority values from public evidence. Once you manually select a value, your saved choice wins. Notes, tags, follow-up dates, manual scores, and pain labels also persist locally.

Contacts

Email, social, and phone evidence

Direct website-domain emails are prioritized. Suspicious placeholder addresses, malformed values, asset-like values, unrelated social-post links, and implausible numeric IDs are filtered where possible. Email send confidence is a local quality estimate only; it does not guarantee mailbox existence or delivery. Source labels remain available so you can verify where each public contact was found.

Evidence

SEO, technical, domain-age, and opportunity signals

Opportunity score focuses on public website-improvement potential. Outreach eligibility focuses on whether a usable contact path exists and whether the lead should be reviewed, contacted, or excluded. Free local SEO summary cards show indexability, canonical, schema, image-alt coverage, local SEO coverage, and locally observed speed. These are screening aids, not guarantees.

Stability

Performance-safe loading for large datasets

LeadLens keeps the main list lightweight and loads complete evidence on demand when a card is expanded. Bulk scanner accepts large saved URL queues and opens websites gradually with a configurable maximum of five active tabs. Progress persists in the local browser database so interrupted queues can resume. Start with one or two active tabs when testing difficult websites. Local speed values are browser observations, not paid external lab reports.

Output

Copy, export, and backup

Copy buttons

Copy emails, socials, technologies, raw lead templates, and ChatGPT-ready raw data place evidence on your clipboard. They do not download files.

Export XLSX

Use Export evidence spreadsheet when you need a spreadsheet or CSV containing visible filtered lead evidence.

Download backup

Use Download backup before major cleanup or reset actions. The JSON file is a safety copy of local browser data.

Local storage

Browser database, cleanup, and reset

Lead records stay inside this Chrome profile. Storage usage warnings appear as the browser database grows. Use Clear when you only want to remove saved leads. Use Full System Reset in Settings only when you want a fresh installation state.

Privacy

Local-first by design

Saved lead records are stored locally in the browser database unless you intentionally copy content, export an XLSX spreadsheet, or download a JSON backup. LeadLens works with public website evidence.

Support

Troubleshooting checklist

  • Retry websites that timed out or returned a verification page.
  • Keep focus rotation enabled for difficult bulk scans.
  • Download a backup before cleanup or reset.
  • Use Full System Reset only when you want to remove all local records and settings.
